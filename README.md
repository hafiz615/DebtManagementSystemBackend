# DebtManagementSystem

The Debt Management System (DMS) optimizes debt settlement for individuals and businesses. Integrated with HotProspector CRM and MoneyThumb for financial data, plus AI modules for analysis. Includes Payment Gateway Integration in Authorize.Net for secure, efficient payment processing.

# Clone Repo

git clone git@github.com:SanaAhmedR/DebtManagementSystem.git

# Change Directory

cd folder_name

# Install dependencies

npm install

# Run on Local

npm run dev

# Start the server

npm start
